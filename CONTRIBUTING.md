Contributing to NEXORA Fire TV

Thank you for your interest in contributing to NEXORA Fire TV! Every helpful contribution matters, including documentation improvements, bug reports, accessibility fixes, and new features.

Getting Started

1. Explore the "NEXORA Fire TV repository" (https://github.com/Danesh9490/nexora-firetv).
2. Read the README for project features and setup information.
3. Check existing issues before starting work.
4. For larger changes, open an issue to discuss your idea first.

Ways to Contribute

- Report bugs and unexpected behavior.
- Improve documentation and setup instructions.
- Improve keyboard navigation and accessibility.
- Improve the responsive layout for mobile and desktop.
- Add or improve automated tests.
- Suggest useful activities and user experience improvements.

Development Guidelines

- Keep changes focused and easy to review.
- Use clear, descriptive names in code.
- Follow the existing project structure and coding style.
- Never commit API keys, passwords, or other secrets.
- Keep the Groq API key on the backend; never expose it in frontend code.
- Test your changes before submitting a pull request.

Submitting a Pull Request

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Test the changes and review your diff.
5. Commit with a clear message.
6. Open a pull request describing what changed, why it helps, and how you tested it.
7. Link any related issue.

Commit Message Examples

- "docs: improve setup instructions"
- "fix: improve keyboard focus visibility"
- "test: add API validation tests"
- "docs: add contributor guidelines"

Need Help?

If you are unsure where to start, look for issues labeled "good first issue" or open an issue to ask a question.

Thank you for helping make NEXORA better!
